# 本地工具管理系统 - M1~M3 可运行代码骨架

> 覆盖：Tauri + Vue 骨架、左右布局、配置读取、CMD 目录扫描、README H1 解析、卡片渲染

------

## 前言

##### 生成一个本地应用工具管理系统Tauri + Vue，仿天狐工具箱UI

1. 左侧为目录栏，作为工具分类目录
   1. 左侧菜单目录由配置文件中编辑写入
2. 右侧内容区域为具体工具展示列表，
   0. 目录为D:\Py Scripting tool\cmd_tool
   1. 展示列表有指定的文件目录扫描其一级子目录进行读取渲染和新增列表项（exe启动的一类的工具）
        1. 指定的文件目录扫描其一级子目录进行读取渲染的为非exe启动的工具即通过CMD进行使用
   2. exe类工具在别的目录需要我手动输入工具的存放位置的绝对路径，
   3. 列表样式为长方形框，包括工具标题，工具使用文档一键打开，工具命令窗口一键打开，工具目录一键打开
      1. 工具标题由工具目录的根目录的文件README.md中H1标题获取
      2. 使用文档Ops.md在工具的根目录，使用文档为弹窗形式打开，高度为视口高度内容区域进行滚动，宽度自适应，右上角点击关闭
      3. 工具分为两种一种为exe启动，一种为命令行窗口的形式

```rust
use crate::models::Tool;
use std::fs;
use std::path::{Path, PathBuf};

/// 从 Markdown 中提取第一行 H1（# 开头）
fn extract_h1(md_path: &Path) -> Option<String> {
    let content = fs::read_to_string(md_path).ok()?;
    for line in content.lines() {
        let trimmed = line.trim();
        if trimmed.starts_with("# ") {
            return Some(trimmed[2..].trim().to_string());
        }
    }
    None
}

/// 生成稳定的 id（简单用路径 hash）
fn make_id(path: &str) -> String {
    use std::collections::hash_map::DefaultHasher;
    use std::hash::{Hash, Hasher};
    let mut h = DefaultHasher::new();
    path.hash(&mut h);
    format!("{:x}", h.finish())
}

#[tauri::command]
pub fn scan_cmd_tools(path: String, category_id: String) -> Result<Vec<Tool>, String> {
    let root = PathBuf::from(&path);
    if !root.exists() {
        return Err(format!("扫描目录不存在: {}", path));
    }
    if !root.is_dir() {
        return Err(format!("不是目录: {}", path));
    }

    let mut tools = Vec::new();

    let entries = fs::read_dir(&root).map_err(|e| e.to_string())?;
    for entry in entries.flatten() {
        let dir = entry.path();
        if !dir.is_dir() {
            continue;
        }

        let dir_name = dir
            .file_name()
            .map(|s| s.to_string_lossy().to_string())
            .unwrap_or_default();

        // 标题：优先 README.md 的 H1，否则用目录名
        let readme = dir.join("README.md");
        let title = if readme.exists() {
            extract_h1(&readme).unwrap_or(dir_name.clone())
        } else {
            dir_name.clone()
        };

        // 文档：Ops.md
        let ops = dir.join("Ops.md");
        let doc_path = if ops.exists() {
            Some(ops.to_string_lossy().to_string())
        } else {
            None
        };

        // 图标：icon.png
        let icon_file = dir.join("icon.png");
        let icon = if icon_file.exists() {
            Some(icon_file.to_string_lossy().to_string())
        } else {
            None
        };

        let path_str = dir.to_string_lossy().to_string();
        tools.push(Tool {
            id: make_id(&path_str),
            tool_type: "cmd".into(),
            title,
            path: path_str,
            doc_path,
            icon,
            category_id: category_id.clone(),
            available: true,
        });
    }

    tools.sort_by(|a, b| a.title.to_lowercase().cmp(&b.title.to_lowercase()));
    Ok(tools)
}

#[tauri::command]
pub fn read_text_file(path: String) -> Result<String, String> {
    fs::read_to_string(&path).map_err(|e| format!("读取失败 {}: {}", path, e))
}
```

```rust
use crate::models::MenuConfig;
use std::fs;
use std::path::PathBuf;

/// 配置目录：项目运行目录下的 config/
fn config_dir() -> PathBuf {
    // 开发期：以当前可执行文件所在目录为基准，向上找 config/
    // 生产期：可改为 app_data_dir
    let mut dir = std::env::current_dir().unwrap_or_else(|_| PathBuf::from("."));
    // 开发期 cwd 通常是 src-tauri，回退一级
    if dir.ends_with("src-tauri") {
        dir.pop();
    }
    dir.push("config");
    dir
}

#[tauri::command]
pub fn load_menu_config() -> Result<MenuConfig, String> {
    let p = config_dir().join("menu.json");
    let content = fs::read_to_string(&p)
        .map_err(|e| format!("读取 menu.json 失败: {} ({})", e, p.display()))?;
    serde_json::from_str(&content).map_err(|e| format!("menu.json 解析失败: {}", e))
}
```

## 六、Pinia Store

### `src/stores/tools.ts`



```ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import type { Category, Tool } from '../types';
import { loadMenuConfig } from '../api/config';
import { scanCmdTools } from '../api/fs';

export const useToolsStore = defineStore('tools', () => {
  const categories = ref<Category[]>([]);
  const tools = ref<Tool[]>([]);
  const activeCategoryId = ref<string>('');
  const loading = ref(false);
  const error = ref<string | null>(null);

  const activeTools = computed(() =>
    tools.value.filter((t) => t.categoryId === activeCategoryId.value)
  );

  async function init() {
    loading.value = true;
    error.value = null;
    try {
      const menu = await loadMenuConfig();
      categories.value = menu.categories;
      if (categories.value.length > 0) {
        activeCategoryId.value = categories.value[0].id;
      }
      await reloadAll();
    } catch (e: any) {
      error.value = String(e);
    } finally {
      loading.value = false;
    }
  }

  async function reloadAll() {
    const all: Tool[] = [];
    for (const cat of categories.value) {
      if (cat.type === 'scan' && cat.scanPath) {
        try {
          const list = await scanCmdTools(cat.scanPath, cat.id);
          all.push(...list);
        } catch (e) {
          console.warn(`扫描分类 ${cat.name} 失败:`, e);
        }
      }
      // manual / system 类型后续阶段补
    }
    tools.value = all;
  }

  function setActiveCategory(id: string) {
    activeCategoryId.value = id;
  }

  return {
    categories,
    tools,
    activeCategoryId,
    activeTools,
    loading,
    error,
    init,
    reloadAll,
    setActiveCategory,
  };
});
```

## 十一、常见坑

1. **Tauri v2 命令参数命名**：前端传 `categoryId`，Rust 用 `category_id`，Tauri 自动转换；若报"missing required key"，检查是否在 `#[tauri::command]` 上加了 `rename_all = "camelCase"`（本次靠自动转换即可）。
2. **config 目录路径**：开发期 `cwd` 是 `src-tauri`，生产期是 exe 所在目录。当前用"回退一级"适配开发期，发布前建议改用 `app_data_dir` 或与 exe 同级放 `config/`。
3. **Windows 路径转义**：JSON 中 `\` 必须写成 `\\`。
4. **中文目录名**：`to_string_lossy()` 已处理，Rust 侧无问题；若前端显示乱码，检查 `tauri.conf.json` 的 `withGlobalTauri` 与编码设置（默认 UTF-8 正常）。
5. **首次 `cargo build` 较慢**：Tauri 依赖多，首次 3~10 分钟属正常。

```ts
export async function toggleMaximize() { await appWindow.toggleMaximize(); }
export async function closeWindow() { await appWindow.close(); }
```

## 注意事项

1. **`decorations: false` 后无法用系统快捷键拖动**，必须靠 `startDragging()` 或 `data-tauri-drag-region` 属性。

   - 更简洁写法：在标题栏 div 上加 `data-tauri-drag-region`，然后 Tauri 自动处理拖动，连 `onMouseDown` 都不需要：

     

     ```vue
     <div class="titlebar" data-tauri-drag-region>
     ```

     

     （但按钮必须加 `data-tauri-drag-region` 之外的区域，否则按钮点击也会拖动；当前写法已用 `@click` 覆盖，没问题。）

2. **双击标题栏最大化**：`data-tauri-drag-region` 默认支持，自绘时可用 `@dblclick="toggleMaximize"`。

3. **圆角窗口**（可选）：若想 win11 圆角，加 `"transparent": true` 并在 CSS 里给 `.app` 加 `border-radius: 8px; overflow: hidden;`。但透明窗口有性能损耗，按需取舍。

4. **图标**：无边框后任务栏图标仍生效，不用改 `tauri.conf.json` 的 `icon`。

5. **首次拖动可能有延迟**：`startDragging()` 是异步 IPC，快速拖动时体验略逊系统标题栏，可接受。
